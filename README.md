WorldAtlas
WorldAtlas is a React 19 application that provides users with comprehensive information about countries worldwide. Leveraging modern web technologies, it offers an intuitive interface to explore various country details.
Features
- Country Listings: Browse a list of countries with essential details.
- Search Functionality: Quickly find countries by name.
- Detailed Views: Access in-depth information about each country, including population, region, and more.
- Responsive Design: Optimized for devices of all sizes.
Tech Stack
- Frontend: React 19
- Build Tool: Vite
- Styling: CSS
- Languages: JavaScript, HTML
Installation
1. Clone the repository:
 git clone https://github.com/PUSHKAR1532/WorldAtlas.git
 cd WorldAtlas
2. Install dependencies:
 npm install
3. Start the development server:
 npm run dev
 The application will be available at http://localhost:5173.
